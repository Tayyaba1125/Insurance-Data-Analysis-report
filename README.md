# Prism Insurance Data Analysis (Power BI)

## Overview
Interactive Power BI dashboard analyzing insurance policies and claims.

## Key Metrics
- Total Premium Amount: 5.98M
- Total Coverage Amount: 600.55M
- Total Claim Amount: 16.91M

## Dashboard Features
- Number of claims by claim status (Rejected, Settled, Pending)
- Premium amount by policy type
- Count of active vs. inactive policies
- Claim amount by age group
- Filters for gender, policy number, claim number and customer ID

## Key Insights
- Travel policies generate the highest premium (2.5M), followed by Health (1.2M)
- Around 75% of policies are inactive and 25% are active
- Claim amount is highest in the Adult age group and decreases for Elder and Young Adult

## Tools Used
Power BI

## How to Open
Download the .pbix file and open it with Power BI Desktop.
